Cara kerja

Siap dipakai dalam tiga langkah

Tidak perlu belajar lama. Daftar, isi produk, lalu mulai jualan.

  1. 1

    Daftar gratis

    Buat akun dengan email. Pilih isi contoh produk untuk mencoba, atau mulai dari kosong.

  2. 2

    Isi produk dan stok

    Masukkan nama, harga jual, modal, dan stok. Barcode kemasan bisa dipindai dengan kamera.

  3. 3

    Jual dan lihat laba

    Catat penjualan di Kasir. Ringkasan laba dan stok yang menipis langsung tampil di beranda.

Pasang di HP

Dipakai seperti aplikasi, tanpa toko aplikasi

Warung Pintar berjalan di browser dan bisa dipasang ke layar utama. Tidak ada unduhan besar.

Pasang di layar utama

  • Android: buka di Chrome, ketuk menu titik tiga, lalu pilih Pasang aplikasi.
  • iPhone: buka di Safari, ketuk Bagikan, lalu pilih Tambah ke Layar Utama.

Data warung tetap milik Anda

  • Data tersimpan di akun Anda di server dan disalin ke perangkat, jadi bisa dibuka dari HP lain.Data tersimpan di perangkat Anda dan tidak dikirim ke mana pun.
  • Kasir, stok, dan laporan tetap jalan saat sinyal hilang.
  • Unduh cadangan kapan saja, dan hapus semua data dengan satu tombol.
Tanya jawab

Pertanyaan yang sering muncul

Apakah Warung Pintar benar-benar gratis?

Ya. Tidak ada biaya langganan, iklan, atau fitur yang dikunci.

Apakah butuh internet?

Tidak untuk kegiatan harian. Kasir, stok, dan laporan jalan tanpa sinyal. Internet dipakai untuk membuat akun, masuk, dan menyinkronkan data ke server saat tersambung.Tidak. Semua fitur jalan tanpa internet setelah halaman ini terbuka sekali.

Di mana data saya disimpan?

Di perangkat Anda dan di server akun Anda. Setiap perubahan dikirim otomatis saat ada koneksi, jadi data tidak hilang kalau HP rusak atau hilang.Di perangkat ini. Unduh cadangan secara berkala di Pengaturan supaya data aman jika HP rusak atau hilang.

Bisa dipakai di lebih dari satu HP?

Bisa. Masuk dengan akun yang sama dan data akan tersinkron otomatis.Data tersimpan per perangkat. Untuk pindah HP, unduh cadangan dari HP lama lalu pulihkan di HP baru.

Barang saya tidak punya barcode. Apakah tetap bisa dicatat?

Bisa. Barcode bersifat opsional. Di Kasir, cukup ketuk produknya.

Bagaimana jika saya lupa kata sandi?

Pilih Lupa kata sandi di halaman masuk. Tautan untuk membuat kata sandi baru dikirim ke email Anda.Akun disimpan di perangkat sehingga kata sandi tidak bisa dipulihkan lewat email. Buat akun baru lalu pulihkan data dari file cadangan.

Privasi dan syarat penggunaan

Ditulis dengan bahasa sederhana, supaya jelas apa yang terjadi pada data warung Anda.

Kebijakan privasi

Diperbarui 23 November 2026

Data yang dipakai

Saat mendaftar: nama warung, nama pemilik, email, dan kata sandi. Saat memakai aplikasi: produk, stok, penjualan, pengeluaran, dan pengaturan yang Anda catat sendiri.

Untuk apa data dipakai

Hanya untuk menjalankan aplikasi: masuk ke akun, menampilkan laporan, dan menyinkronkan data antar perangkat. Data tidak dijual, tidak dipakai untuk iklan, dan tidak dipakai untuk melacak Anda.

Tempat penyimpanan

Di perangkat Anda dan di akun Anda pada layanan basis data cloud Supabase, dengan server di luar Indonesia. Setiap akun hanya bisa membaca dan mengubah datanya sendiri. Kata sandi disimpan dalam bentuk acak (hash) sehingga tidak bisa dibaca kembali.Hanya di perangkat ini. Tidak ada data yang dikirim ke server.

Layanan lain yang bisa terlibat

  • Pemindai barcode memproses gambar kamera di perangkat dan tidak mengunggahnya. Di sebagian browser, pustaka pemindai diunduh sekali dari jsDelivr.
  • Jika Anda mengisi tautan Google Sheets di Pengaturan, laporan laba dikirim ke spreadsheet milik Anda sendiri.

Kendali Anda

  • Unduh cadangan data kapan saja di Pengaturan.
  • Hapus semua data warung di Pengaturan.
  • Hapus akun beserta seluruh datanya di server lewat Pengaturan, bagian Akun.

Perubahan

Jika kebijakan ini berubah, tanggal di atas ikut diperbarui.
